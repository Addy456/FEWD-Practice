(\*) What is Web Page?

\----------------------

1. A web page is a document, commonly written in HTML, that is viewed in an internet browser.
2. A web can be accessed by entering URL into a browser's address bar.
3. HTML elements tell the browser how to display the content.
4. A web page may contain text, graphics, and hyperlinks to other web pages and files.
